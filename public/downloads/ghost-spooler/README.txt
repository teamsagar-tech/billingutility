========================================================================
   RETAILNODE GHOST SPOOLER - SILENT BACKGROUND INSTALLATION
========================================================================

How to Install:
1. Extract all files from this ZIP to: C:\RetailNode\
2. Open config.json in Notepad to verify or update your Store API Token.
3. Right-click "install-ghost-service.bat" and click "Run as administrator".

That's it! 
- The service will run silently in the background as a Windows Service.
- Zero popups, zero cashier interaction, zero changes to your POS software.
- Check "ghost-service.log" to view live dispatch history.
